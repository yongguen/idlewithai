# 붕어빵 주식회사 (idlewithai)

벽돌 주식회사의 "벽돌을 부순다"는 핵심 테마를 바꿔 만든 **방치형 성장 게임 프로토타입**. 시즈닝게임즈 클라이언트 개발자 과제 제출용입니다.

**▶ 플레이: https://yongguen.github.io/idlewithai/** (모바일 세로 화면 권장, 처음 로딩에 몇 초 걸립니다)

반죽 → 속 → 굽기 → 뒤집기 → 완성의 5단계를 박자 맞춰 누르면 콤보 수익이 터지고, 알바를 채용하면 자동으로 구워집니다.

## 테마 전환

| 벽돌 주식회사 | 붕어빵 주식회사 |
|---|---|
| 벽돌 종류(스테이지 구분) | 붕어빵 종류: 기본 → 팥 → 슈크림 → 치즈 → 황금 |
| 총알 강화 = 데미지↑ | 알바 숙련 = 굽는 시간 단축 |
| 무기 종류 | 알바 종류 5명(반죽·앙금·화덕·뒤집기·포장) |
| 대포 자동 발사 + 터치 | 알바 자동 생산 + 단계 버튼 콤보 |
| 환생 | 프랜차이즈 개점(영구 배수) |
| 파괴 연출·ASMR | 굽는 연출·단계별 효과음 |

자세한 설계와 대응표는 [`Docs/Prototype_Plan.md`](Docs/Prototype_Plan.md), 구현 기록은 [`Docs/Code_Handoff.md`](Docs/Code_Handoff.md).

## 구성

- `assets/scripts/core` — 순수 TS 로직(경제·저장·오프라인·환생·굽기 단계/콤보). `cc` 미사용, node로 테스트
- `assets/scripts/view` — Cocos Creator 컴포넌트(UI·연출·사운드)
- `assets/art`, `assets/audio` — SVG에서 내보낸 그림, 합성 효과음(`tools/make_sfx.py`)
- `tests/` — node 테스트 68개 + 탐욕 봇 시뮬레이션
- `gh-pages` 브랜치 — GitHub Pages로 호스팅되는 릴리스 웹 빌드

## 실행·테스트

```bash
npm test    # 테스트(Node 22.15+)
```

엔진: Cocos Creator 3.8.8. 프로젝트를 열어 `assets/scenes/Main.scene`을 실행하면 됩니다. 웹 빌드는 정적 서버로 열어야 합니다(`python3 -m http.server`).

## 알려진 제한

- 효과음은 합성 파일을 연결했을 뿐 청감 품질은 검증하지 못했습니다.
- 밸런스는 봇 시뮬 위주이며, 실기기·장시간 방치 테스트는 하지 않았습니다.
- 광고·결제·서버·변조 방지는 없습니다. 벽돌 주식회사 분석은 공개 정보 기반이며 직접 플레이한 평가가 아닙니다.
- 기획·코드·검증은 AI(Claude Code, Codex)와 함께 진행했습니다.
