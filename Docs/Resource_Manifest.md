## 1. 공통 규칙

### 1.1 제작 방식 (결정)

- **기본: SVG 직접 작성 → PNG 내보내기.** 시안이 SVG라 도형·그라데이션 문법과 팔레트를 그대로 이어 쓸 수 있고, 출처·라이선스가 전부 자체 제작이 된다. 소스 SVG는 `design/src/…`에 보관(Cocos `assets/` 밖), 내보낸 PNG만 `assets/art/…`에 둔다.
- AI 이미지 생성은 **선택 사항**이며 P2 장식(타이틀 키아트 등)에만 쓴다. 쓰면 §6 기록을 반드시 남기고, 배경 제거·재색칠 등 후처리를 적는다. P0·P1은 AI 이미지 없이 만든다.
- 실제 브랜드 로고, 벽돌 주식회사의 아트·UI 캡처, 실존 캐릭터, 폰트 비허가 파일은 쓰지 않는다. 시안 SVG 안의 도형 `bun`, `spark`는 재사용 가능(자체 제작).
- 글자는 이미지에 굽지 않고 Label 컴포넌트로 처리한다(현지화·수치 변경 대비). 예외는 점포 간판 텍스트 한 줄만 이미지에 포함해도 된다.

### 1.2 스타일 · 팔레트

플랫한 벡터, 둥근 모서리, 약한 하이라이트, 외곽선 없이 면 분할(시안과 동일). 그림자는 아래로 짧게 `#854A20`, 투명도 16%.

| 용도 | 색 |
|---|---|
| 하늘 상단 / 하단 | `#FFEAC2` → `#FFF9EA` |
| 주 버튼 | `#FFB347` → `#ED7830` |
| 진한 갈색(제목·바·간판) | 시안의 `#6B3A24` 계열 (제작 시 SVG에서 값 추출) |
| 붕어빵 몸통 / 노릇 / 하이라이트 / 지느러미 / 눈 | `#E8A54B` / `#A95023` / `#FBD184` / `#DA8B3D` / `#703721` |
| 화덕 | `#47505C` → `#242B36` |
| 천막 강조 | 시안의 주황 `#E8643C` 계열과 흰색 줄무늬 |

색값은 시안 SVG에서 추출해 `design/src/palette.json`으로 먼저 고정한다(P0 선행 작업). 위 표의 갈색·주황은 근사값이다.

### 1.3 포맷 · 규칙

- PNG-32(알파 포함), sRGB, 프리멀티플라이 알파 아님. 배경이 있는 것만 불투명 PNG-24.
- 파일명: 소문자 snake_case, `분류_이름_변형_상태`. 예 `bread_plain_done`. 한글·공백 금지.
- 폴더: `assets/art/{bg,store,bread,equip,char,ui,fx,icon}/`. 같은 폴더끼리 Cocos AutoAtlas로 묶는다(`bg`는 제외, 개별 텍스처).
- 해상도는 기준 1080 폭의 1배만 제작한다(@2x 없음). 텍스처 한 변 2048 이하, 2의 거듭제곱 강제 없음.
- 9-slice가 필요한 UI는 표에 `9s(좌,우,상,하)`로 보더 값을 표기한다.
- 상태 열: `todo`(미착수) / `wip` / `done` / `review`(출처·인게임 검수 대기). 현재 P0/P1 시각 리소스는 `review`이며 P2는 `todo`.

## 6. 라이선스 · AI 출처 기록 방식

리소스를 하나 추가할 때마다 `Docs/Asset_Log.md`(다음 세션이 생성)에 한 행을 추가하고, 상태를 `review`로 올린 뒤 기록 확인 시 `done`으로 바꾼다. 이 문서의 표와 파일명을 1:1로 맞춘다.

| 열 | 설명 / 허용 값 |
|---|---|
| id | 파일명(확장자 제외) |
| source_type | `self-svg`(자체 SVG 제작) / `self-draw` / `ai-image` / `cc0` / `licensed` / `derived`(시안 SVG에서 파생) |
| tool | 사용 도구와 버전(예: 손으로 쓴 SVG + rsvg-convert/inkscape CLI 버전, AI이면 모델명과 버전) |
| created_at | 제작일 YYYY-MM-DD |
| prompt_or_basis | AI이면 프롬프트 요약(원문 전체 보관 위치), 파생이면 원본 파일·요소 id |
| post_edit | 배경 제거·색 보정·리사이즈 등 사람이 한 후처리 |
| license | `owned`(자체) / `CC0-1.0` / `OFL-1.1` / 상업 이용 가능 여부 조건 |
| source_url | 외부 자료 URL (없으면 `-`) |
| attribution | 표기 필요 여부와 문구 |
| reviewed_by / reviewed_at | 사람이 확인한 사람·날짜. 확인 전에는 `done` 금지 |

운영 규칙:

1. `ai-image`는 생성 서비스 약관상 상업·제출 이용이 가능한지 확인하고, 불명확하면 쓰지 않는다. 실존 인물·브랜드·타 게임 캐릭터를 연상시키는 프롬프트는 금지.
2. 외부 리소스(`cc0`, `licensed`)는 다운로드 시점의 라이선스 문구와 URL을 남긴다. 확인하지 못한 것은 `licensed`가 아니라 **사용하지 않는다**.
3. 제출물에는 `Asset_Log.md`를 요약해 "자체 제작 N개 / AI 생성 N개 / 외부 N개"를 표시한다. AI 사용 범위는 코드 보조, 문서 작성, (있다면) 이미지 생성으로 나눠 적는다.
4. 시안 PNG/SVG는 사용자(지원자) 본인이 작성한 자료로 취급하되, 그 생성 경위(어떤 도구로 만들었는지)는 사용자에게 확인 후 `Asset_Log.md` 첫 행에 적는다. **이 부분은 아직 확인하지 않았다.**
5. 리소스 파일 추가·수정은 `.meta` 파일과 함께 커밋한다(Cocos가 생성). 라이브러리 폴더(`library/`, `temp/`)는 커밋하지 않는다(현재 `.gitignore`가 제외 중).
