# 붕어빵 주식회사 — 리소스 제작 인수인계

- 작업일: 2026-11-24
- 범위: Cocos Creator 3.8.8용 시각 리소스. 코드·씬·저장 방식은 변경하지 않았다.

## 결과

| 구분 | 결과 |
|---|---|
| P0 시각 리소스 | 49개 전부 제작 |
| P1 시각 리소스 | 31개 제작: 6~11단계 로드맵, 빵 변형, 설비, 불꽃·효과, 알바 동작, 손님, 열 게이지, 아이콘 |
| 원본 | `design/src/`에 SVG 80개, 팔레트 JSON, 재생성 스크립트와 목록 JSON |
| 납품 | `assets/art/{bg,store,bread,equip,char,ui,fx,icon}/`에 PNG 80개 |
| 출처 | `Docs/Asset_Log.md`에 파일별 80행. 외부 스톡 및 AI 이미지 생성 없음 |

매니페스트의 `ui_progress_track`와 `ui_progress_fill` 16×40 9-slice 좌우 보더 20px은 각각 **6px**로 수정했다(가운데 4px). `ui_card_price_chip`의 세로 32px+32px도 높이 43px에 맞지 않아 상하 18px로 수정했다. 열 게이지의 9-slice 보더도 수치로 명시했다.

## 검수

- `asset_report.py --expect-size ... --require-alpha --json`을 80개 전체에 실행: **80/80 통과**. 불투명 배경 3개는 알파 검사 대신 RGB 확인.
- 세 묶음의 체커보드 콘택트 시트에서 실루엣, 색상, 투명 배경을 확인했다. 포장마차 단계의 1080×1920 장면을 540×960으로 축소하여 매장·캐릭터·UI 가독성도 확인했다. 축소 합성에는 Cocos의 9-slice 확대와 Label 텍스트가 적용되지 않는다.
- SVG와 PNG 크기는 파일별로 일치하고, P0/P1 투명 PNG에는 실제 0 알파 픽셀이 있다. `bg_sky_day`, `ui_tabbar_bg`, `ui_dim`은 불투명 RGB다.
- 원본 시안의 면 분할, 주황 천막, 갈색 화덕, 크림색 거리와 붕어빵 색을 이어 썼다. 점포 1~5단계는 서로 다른 외형으로 구별된다.

## 남은 점

1. **인게임 검수:** Cocos 에디터에서 Sprite `SLICED` 모드와 위 보더를 지정하고, 실제 UI 폭·피벗·점포 바닥선을 확인해야 한다. 이 세션은 코드와 씬을 수정하지 않아 실행 화면은 검수하지 않았다. Cocos `.meta` 파일은 에디터가 에셋을 읽을 때 생성된다.
2. **출처 최종 확인:** 기존 `design/붕어빵주식회사_메인화면_시안.svg`의 원 제작 경위는 확인되지 않았다. 시안에서 파생한 파일의 귀속은 `Asset_Log.md`에 보류 표시했다. 현재 매니페스트 상태 `review`는 기술 검수 완료와 사람의 출처·인게임 확인 대기를 뜻한다.
3. **P1 음원·폰트:** 시각 P1은 제작했으나, 매니페스트 §5.1 한글 폰트 번들과 §5.2 P1 사운드는 제작하지 않았다. 외부 폰트 라이선스 확인 및 오디오 제작이 별도로 필요하다. P2도 범위 밖이다.

제작 소스는 `python3 design/src/generate_assets.py`로 재생성할 수 있다. PNG는 `rsvg-convert`로 내보냈다. 웹 저장은 기획대로 브라우저 `localStorage`를 사용하며 SQLite는 쓰지 않는다.
