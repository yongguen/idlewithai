## 2. 확정한 결정 (자세한 이유는 Plan §0)

세로 1080×1920 FIT_WIDTH / 1~5단계 + 첫 환생 구현, 6~11은 로드맵 표시 / 저장은 `sys.localStorage` 키 `bungeoppang.save.v1` / 큰 수는 double + 한국식 단위 표기 / 로직은 `cc` 비의존 순수 TS / 광고·결제 미구현 / 리소스는 SVG 자체 제작 우선, AI 이미지는 선택(P2).

핵심 수치: 판당 기본 8·60·480·4,200·40,000, 확장 비용 3만·300만·4억·600억, 환생 조건 5단계 + 회차 매출 1e13, FP = floor(5×√(매출/1e13)), FP당 판당 수익 +20%, 오프라인 50%·기본 2시간.

## 3. 검증되지 않은 점 (중요)

1. **밸런스는 인게임 미검증.** 탐욕 봇 파이썬 시뮬레이션을 몇 차례 돌려 확장 비용·환생 목표를 골랐다. 추정은 1회차 환생 약 18~22분, 2회차(FP 5) 약 9~11분이다. 시뮬레이션은 알바·화덕·레시피·설비 구매만 모델링했고 황금 불판은 넣지 않았다. 구현 후 TS로 같은 봇을 돌려 ±25%를 확인하고 어긋나면 확장 비용만 조정할 것.
2. 시뮬레이션 파일은 프로젝트에 저장하지 않았다. 재현이 필요하면 Plan §4.1~4.5 공식으로 다시 작성해야 한다.
3. Cocos Creator 3.8.8 API(`sys.localStorage`, AutoAtlas, 해상도 정책 설정 등)는 이 세션에서 에디터로 확인하지 않았다. 제작 세션이 첫 단계에서 확인할 것.
4. 시안 대비 좌표는 SVG 원본을 읽어 Resource_Manifest §8에 옮겼으나 Plan §2.3 화면 표의 y 범위는 개략값이다. 충돌하면 Manifest §8을 따른다.
5. 시안 PNG/SVG의 제작 경위(도구)를 사용자에게 확인하지 않았다. 출처 기록 첫 행에 필요하다.
6. 폰트(Noto Sans KR/Pretendard)의 현재 라이선스 문구와 파일 출처는 확인하지 않았다. 제작 시 확인 필수.
7. 실제 플레이 가능한 빌드, 웹 링크, 스크린샷은 없다. 벽돌 주식회사를 직접 플레이하지 않았으며 Q2 등 제출문에서 플레이한 것처럼 쓰면 안 된다.
8. `work` 기록: 작업 추가·완료 로그 명령을 실행했으나 성공 여부는 별도 확인하지 않았다.
9. 리소스 개수는 집계하지 않았다.
